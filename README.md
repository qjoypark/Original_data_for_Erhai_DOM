# Original data and code for "Seasonal Environmental Variability and Asynchronous Changes in Dissolved Organic Matter in Lake Erhai"

This repository contains the original data, derived data, and R code supporting the  
manuscript *Seasonal Environmental Variability and Asynchronous Changes in Dissolved  
Organic Matter in Lake Erhai* (submitted to *Water*, MDPI).

## Contents

| File              | Description                                                                  |
| ----------------- | ---------------------------------------------------------------------------- |
| `野外环境数据-all.xlsx` | Raw field environmental data (Raw_Field_Environmental_Data.xlsx)             |
| `野外环境数据-处理.xlsx`  | Processed field environmental data (Processed_Field_Environmental_Data.xlsx) |
| `野外数据-卡尔森指数.xlsx` | Field data and Carlson trophic state index (Field_Data_Carlson_TSI.xlsx)     |
| `Doc.xlsx`        | Dissolved organic carbon (DOC) concentrations                                |
| `DOM-组分.xlsx`     | DOM fluorescence components (DOM_Fluorescence_Components.xlsx)               |
| `荧光指数.xlsx`       | Fluorescence indices (FI, HIX, BIX, etc.)                                    |
| `Fn(355).xlsx`    | Fluorescence intensity at 355 nm excitation                                  |
| `chl-a0DOC.xlsx`  | Chlorophyll-a, DOC and related parameters                                    |
| `数据汇总.xlsx`       | Compiled dataset used for statistical analysis                               |
| `相关性 .xlsx`       | Correlation matrices                                                         |
| `相关性-改动 .xlsx`    | Revised correlation matrices                                                 |
| `初试代码.R`          | Exploratory R script (data exploration)                                      |
| `投稿版-测试.R`        | Final R script reproducing all analyses and figures in the manuscript        |

## Software

All analyses were performed in R (R Core Team, R Foundation for Statistical Computing,  
Vienna, Austria). Scripts are provided as plain `.R` files and are self-contained; input  
files are read from the repository root.
